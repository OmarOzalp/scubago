# My Home Implementation Plan

**Goal:** A personal island that fills with discovered marine life and expands with collection progress.
**Architecture:** Derive growth from existing sightings; isolate vector artwork and animation from the screen. Store validated home preferences per owner with AsyncStorage.
**Tech Stack:** Expo SDK 57, React Native, TypeScript, SVG, Animated, Zustand, AsyncStorage.
**Spec:** docs/superpowers/specs/2026-09-14-my-home-design.md

## Constraints
- Expo versioned docs read before code; use SDK 57 compatible dependencies.
- Only personal non-demo known species contribute; repeated species count once.
- All residents accessible, up to 12 animated at once; support reduced motion.
- Home preferences saved locally per owner. Existing account and sightings sync unchanged.
